# Second Serve

Second Serve is a full-stack web application designed to reduce food waste and combat food insecurity by connecting businesses with surplus food to local food banks and shelters. The platform provides a centralized system for managing food donations, coordinating pickups, and tracking donation records.

## Project Overview

Millions of pounds of edible food are wasted each year while many individuals and families experience food insecurity. Second Serve addresses this problem by creating a business-to-business (B2B) platform that enables businesses to quickly donate surplus food to organizations that can distribute it to those in need.

The application streamlines the donation process, improves logistics, reduces waste, and helps ensure food reaches recipients before it spoils.

## Key Features

- User authentication and role-based access control
- Food donation listing and management
- Real-time donation claiming and reservation system
- Donation tracking and record keeping
- Food expiration monitoring
- Location-based matching between donors and recipients
- Volunteer pickup and delivery coordination
- Donation reporting for tax and compliance purposes

## Target Users

### Recipients

## Technology Stack

The project will be developed using the **MERN Stack**:

- **MongoDB** – Database
- **Express.js** – Backend Framework
- **React.js** – Frontend Framework
- **Node.js** – Server Runtime

## Project Vision

Second Serve provides a reliable and efficient platform for transferring surplus food from businesses to organizations that serve people experiencing food insecurity. By centralizing donation management and logistics, the platform helps reduce food waste while maximizing community impact.
